## 五分鐘驗收

1. **藥袋辨識**：新增藥品，拍照或上傳圖片；逐項核對用量、頻次及途徑，另從手上包裝抄錄完整許可證（含前綴），或完整品名、含量與劑型以核對產品。勾選用法不會確認產品，候選也不是核對證據。資料不足可先保存待核對，再補拍或補資料；補拍返回後尚未保存的用法應保留。
2. **仿單說明**：在「我的藥品」選擇產品已核對、用法已確認且已收錄來源的藥品，閱讀用途、用法及警語，展開「對照仿單原文」。產品待核對時應先補資料，不能開啟仿單、學習或舊回答；已核對但尚未收錄來源時會顯示資料不足。
3. **理解測驗**：先選錯一題、查看解說，再改正。返回全部藥品後重新進入，答案與進度應相同；重新整理後也應保留已保存答案。
4. **用藥問答**：勾選至少一款產品已核對且用法已確認的藥品，輸入例如「請依仿單說明適應症，並附上原文來源」，按「送出」。Enter 為換行。看到回答後展開引用，重新整理確認仍有效的問答紀錄可接續；待核對產品不能選取，直接呼叫 API 也應在建工作及扣額前回 `409 identity_unconfirmed`。
5. **切換與恢復**：尚未送出的問題可在同一分頁切換「我的藥品」後返回；處理中切頁再回來不會建立第二筆相同工作。連線失敗可保留問題重試；若已送出成功但紀錄讀取失敗，重新讀取紀錄即可。

沒有藥品、藥品尚未確認或尚未勾選時，問答輸入區會直接說明下一步。問題草稿保留於本次分頁的記憶體，重新整理或登出會清除；已成功送出的問答由帳號紀錄保存。

雲端目前在重新整理後需要再次登入；使用原帳號即可接續已保存的藥品、問答與測驗進度。本次已實際核對重新登入後的紀錄。
