## 版本與可追溯性

基準 commit 為 `1ac3dc3d5727bddafa04ec22ab9c890bbe177b44`。本輪在該基準上修改，逐批 `plan.json` 保存實際伺服器、共用 schema、評估工具與 lockfile 的 SHA-256；不是只用未提交的基準 commit 指認測試版本。

真實請求使用專案既有 OpenAI 官方端點、`gpt-6-luna`、推理 `none`。每批保存請求與回應模型、設定、HTTP 請求、usage、計時、原始候選與發布內容。執行於隔離的本機檔案，沒有建立雲端帳號、修改生產資料庫或發布來源。故障注入則使用本機假上游，與真實模型結果分開計算。

所有原圖、原始仿單、參考答案、輸出及待評核清單保存在 Git 忽略的 `.local/jcmit-evaluation/`。原始失敗與前一版本結果不被重跑覆蓋。

以上七批合計 103 次 HTTP，已知 token 的保守費用估算為 **US$0.1101935**，不是帳單。採官方 Luna 長上下文最高輸入 US$0.25／百萬 token、輸出 US$0.75／百萬 token；部分視覺回應沒有 cache-write 細項，所以精確費用保持未知，不當作零。價格來源：[官方模型頁](https://developers.openai.com/api/docs/models/gpt-6-luna)，2026-10-20 核對。後續修正重測費用另列。

小批視覺的兩個嚴格比對失敗，是可接受答案未包含照片同列的完整口服標示與完整英文品名。重讀原圖後只在開發答案 v2 加入字面等價值，保存變更紀錄；不能把 1/3 到 9/9 當作純模型改善。

兩張新增實拍原批次的主要問題為：包裝量與濃度混在一起、明確外用標示未補回，以及低解析度的 0.21 錠偶發留白。修正後五圖的 v3 共有 13/15 嚴格整袋符合，這是已參與修正的開發回歸表現，不能當獨立測試準確率。v3 視覺端到端 p50 為 8.963 秒、p95 為 24.302 秒；每圖只有三次，小樣本不代表現場延遲上限。

v3 的兩個嚴格失敗均為第二次重複：輸出 `Secorine syrup（息咳寧糖漿）`、`ProCATerol (Pocathma-mini)`，而原先答案只列各自分開的名稱。exact-name 一對一匹配各算一個漏列及一個誤增；其餘欄位實際符合參考，並非這批又漏讀 0.21 錠。兩筆的目錄候選卻同時為空，因此也存在合併名稱查找的可用性缺口，不能只歸因於評分格式。原批及參考答案保持不變。

新增仿單 v3 的六個部分完成，來自 Vimax 與 Cetirizine 各三情境；有用途與部分題目，但警語題目未覆蓋每個已識別主欄。Famotidine 三案在呼叫模型前由 `source_requires_review` 擋下，PDF 抽取順序有右欄先於左欄及欄尾不完整問題。保留失敗分母，沒有放寬來源保護來取得成功率。

36 個仿單情境的首次擴大結果是 **27 個結構完整、6 個部分完成、3 個來源阻擋**，共 66 次 HTTP。上述 v2／v3 首次擴大批次的辨識相關程式版本不同，但這些批次之間的 `grounded` 來源與發布邏輯尚未改動。結構完整與引用字串吻合均不能替代語意正確、所有條件保留或題目唯一正解的人類評核。

同次生成的候選組共 63 條說明、61 題；發布組共 120 條說明、105 題，按 `q/options/answer` 精確去重為 56 題，不能稱 56 個獨立學習目標。候選 125/125、發布 225/225 引用字串可在指定來源找到；題目格式分別 61/61 與 105/105 合格。這些都是機械指標。349 個人工評核項目仍全部待評，語意正確率維持未評估。

## 修正與工程驗證

本輪修正包括：明確外用標示的字面恢復；明示容器包裝後綴與濃度分開；完整英文外用泡沫液名稱的保守候選查找；恢復欄位後只替換純缺漏提示，其他影像模糊或不確定警告保留；用藥問答不能送出時的就地原因與操作入口、空白與重複送出防護、失敗重試保留問題。

問答問題的雲端重現條件是沒有可選的已確認藥品，原頁面只在側欄說明原因。修正沒有繞過藥品確認；使用者需先新增／確認，再勾選本次詢問的藥品。

修正中另補上否定、空白未勾選框、名稱欄、隔空白的負號及正式品名濃度衝突的負例。完整中英文括號品名只有兩半均對應同筆官方資料、含量及劑型無衝突時才提供候選；固定目錄唯讀檢查的息咳寧候選為 040833。Procaterol 複合名涉及鹽類與單位別名，未新增寬鬆匹配，仍需人工核對。

v14 新增「特殊族群注意事項、病人使用須知、包裝及儲存」三種完整安全主欄；保留實際欄名與原文，不用摘要替代條件。「其他」只作分段邊界，通用「儲存／貯存／儲存方式／儲存條件」仍未納入安全主欄自動覆蓋，不宣稱全仿單所有安全資訊完整。安全題無法保留條件時維持未出題，不硬補為完整。新來源已用於修正，修正後批次全部是開發回歸。

安全欄位顯示涵蓋率以解析器已辨識主欄為分母；測驗涵蓋率只表示該欄至少一題，不代表所有子條件已評量或已完成臨床安全評核。生成前的 28 個必查主欄與 82 個錨點也不能代替這個執行時分母。

三輪隔離恢復驗收各 10/10，共 **30/30**；每輪 23 次 loopback 上游請求及 5 次服務程序啟動。覆蓋程序中斷、持久化、逾時重傳、回應遺失與重試去重；沒有重開作業系統。三輪前後原本 `.local/db.json` 雜湊一致。這是本機故障注入，不是本輪的雲端／手機實測。
