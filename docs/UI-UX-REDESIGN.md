# 藥智通介面與操作

設計範圍：日常手機使用為主，另設研討會展示入口。

## 日常操作

- `#home`：先呈現今日排程與服藥紀錄，旁邊提供拍藥袋及閱讀入口。
- `#add`：照片預覽、辨識結果、核對用法三步。選擇候選後將焦點帶到核對表單；仍由使用者逐項確認，沒有辨識到的值保持空白。
- `#learning`：先選一份學習內容，再閱讀單筆說明。可直接跳用途、完整警語或理解測驗。
- `#learning?record=<id>&section=quiz`：重新整理仍停在指定紀錄／段落。進度以實際保存結果為準。
- `#jobs`：獨立查看處理紀錄、恢復與重試；個人設定中仍保留既有入口。

手機底部提供今日、藥品、拍藥袋、小教室、更多。家人照護、問答、紀錄及展示可從更多開啟。選單支援鍵盤循環與 Escape 關閉，收起後不會留下可聚焦的隱藏連結。

## 研討會操作

入口為 `#demo`。每次選一款已有說明的藥，按辨識、仿單說明、理解測驗三步展示。`record` 與 `step` 放在網址，重新整理仍可繼續。

- 明確標示「已保存結果」。切換步驟只讀取既有資料，不自動重送 AI 任務。
- 有對應辨識任務才顯示該任務入口；沒有辨識紀錄不冒稱辨識完成。
- 「現場拍一張藥袋」另進實際辨識流程；保存後帶著新藥品進入清單，由使用者開啟仿單說明，再帶新說明回展示。
- 顯示的已完成狀態與題數來自實際資料。測驗會真的保存答案，錯答、未保存或保存失敗不當成完成。
- 仿單主欄全文、每項引用、題目原文依據與個人處方的區分保留。測驗仍只抽查各欄重點。

## 一套介面、同一個入口

正式服務統一使用8085。日常首頁為 <http://127.0.0.1:8085/#home>，研討會展示為同一網站內的 <http://127.0.0.1:8085/#demo>；工作中的8086預覽入口撤下，不提供第二套版本。

雙擊專案內的 `啟動藥智通.cmd`，啟動後選「本機使用者」。本機仍使用原有 `.local/seminar-demo-expanded-v13-20261020`，不以工作中的副本覆蓋原資料或金鑰。

介面以「用藥手帳」為設計主軸：首頁先顯示今天排程；藥品以編號檔案呈現，學習內容以閱讀目錄呈現；完整仿單文字採章節邊欄與閱讀主欄。紙白、墨綠及陶土色用來區分結構，正確、錯誤、待確認仍有各自的語義樣式。沒有依靠外部字型下載。

這些本機資料、照片與金鑰不隨 Git 同步；一般新裝置仍從空白資料開始，`#demo` 會顯示準備指引。新裝置資料準備方式與辨識限制以 README 為準。

本次介面檢查使用合成測試服務與已保存結果，不為改版另行呼叫付費 AI。UI 改版不擴大原有的照片辨識或臨床適用性驗證範圍，也不要求整台電腦重開機。
