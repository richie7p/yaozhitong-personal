# 藥智通系統介紹與研討會展示講稿

2026-10-20｜以現行雲端 TEST 為主，使用合成藥袋與咳服錠既有案例。展示重點是「辨識後核對、閱讀時有依據、作答後能接續」。

## 一分鐘介紹

> 拿到藥袋後，我們可能看得見藥名，卻不容易把袋上的用法、仿單裡的提醒和自己的服藥紀錄連起來。藥智通把這些資訊放在同一個操作流程中：先拍照或上傳藥袋，核對辨識出的藥名與用法，再閱讀附有官方仿單原文的說明，最後用理解測驗回看重點。答案與進度會保存，下次可以接著閱讀；日常也能記錄服藥及設定提醒。今天會以合成藥袋示範這三步，讓大家看到資料如何從照片變成可以核對、閱讀和練習的內容。系統目前提供資訊整理與紀錄，沒有藥師簽核流程，也不替使用者判斷是否適合用藥或調整處方。

## 功能如何幫助使用者

- **拍照與核對**：減少逐欄輸入，保留辨識原文與待確認欄位，由使用者對照照片確認。
- **仿單閱讀**：用途、袋身用法與完整警語分開呈現；每項說明可展開原文、頁碼及來源版本。
- **理解與接續**：答錯可回看本題依據，再修改答案；保存進度，避免每次重新開始。
- **日常紀錄**：整合藥品、服藥紀錄、提醒及家庭藥箱，讓資訊回到日常使用情境。

## 展示前準備

先登入展示帳號，確認「研討會展示」可選到咳服錠，且有對應辨識紀錄與說明。雲端目前只發布咳服錠026087這份仿單；酵素膠囊可展示辨識，不安排它的雲端仿單生成。

## 七分鐘操作與講稿

| 時間 | 畫面操作 | 可直接說的話 |
|---|---|---|
| 0:00–1:00 | 「研討會展示」→「選擇展示藥品」選咳服錠，指出「已保存結果」。 | 使用上方一分鐘介紹，補充：「這份是預先完成的內容，接下來先示範一次實際辨識。」 |
| 1:00–2:40 | 「現場拍一張藥袋」→「上傳照片」→選合成袋→「開始辨識」。選咳服錠候選，核對「每次劑量」「劑量單位」「頻次原文」「給藥途徑」；核對後勾「我已對照藥袋確認藥品與用法」→「確認並儲存藥品」。 | 「辨識結果先進入核對，沒有看清楚的欄位留白。這張合成袋的PRN會預選『需要時才使用（不排定時提醒）』，但仍要由使用者確認。」 |
| 2:40–4:20 | 「我的藥品」→「仿單說明」→「帶這份說明繼續展示」。看「用途與用法」「完整警語」，展開「對照仿單原文」。 | 「這裡把仿單用途與我核對的袋身用法分開。我們可以查看副作用、注意事項與警語，並追到026087、第1頁及來源版本。仿單用途不代表醫師為個人開藥的原因。」 |
| 4:20–6:00 | 「下一步：理解測驗」。已完成內容先按「重新複習」。選錯一題→「檢查答案」→看「再看一下：」及「回看這題的仿單依據」→改答→「檢查答案」→「下一題」。 | 「答錯時可以直接回到這題的原文，再檢查理解。題目抽查重點，不能取代完整閱讀。」時間足夠才完成全部題目；只操作一題就明說是一題示範。 |
| 6:00–6:30 | 重新整理，再查看「用藥小教室」或展示頁的實際進度。 | 「剛才的答案已保存，下次可以從這裡接續。」不為展示保存而重新登入。 |
| 6:30–7:00 | 回到「藥袋辨識／仿單說明／理解測驗」三步。 | 「目前已跑通雲端完整流程，也完成Android鎖屏提醒實測。接下來會擴充來源、紙本照片及長期使用驗收。」 |

「重新複習」不清空舊答案：原本4／4的紀錄答錯一題，可能變成3／4。請讀實際畫面，不固定說成從0題開始。展示入口切換步驟不重新呼叫AI，但測驗答案會真正保存。

## 五分鐘版本與失敗接續

五分鐘版全部使用「已保存結果」：0:00–0:40介紹；0:40–1:40展開「查看已保存的藥袋辨識文字」，核對用量與頻次；1:40–3:00閱讀安全欄與引用；3:00–4:30示範一題錯答、看原文、改正；4:30–5:00重新整理並說明範圍。開頭明說模型結果已預先完成。

即時辨識或生成超出該段時間，就切回保存內容並說：「這次請求保留在處理紀錄，先用預先完成的內容接續。」不要反覆按送出。到「處理紀錄與恢復」可查看狀態；成功辨識用「繼續核對辨識結果」，失敗辨識用「重新上傳藥袋」，其他工作僅在提供按鈕時用「使用原輸入重試」。

若雲端連線中斷，改用事先準備好的本機8085資料，明說已切換本機。私人資料不承諾離線可讀寫；本機副本需提前啟動確認，不能把下載程式當成已有展示資料。

## 七頁投影片內容大綱

1. **藥智通：看懂用藥，記錄日常**。一句定位與三步流程圖，先讓聽眾知道要解決什麼閱讀與紀錄問題。
2. **資訊為何容易分散**。藥袋、仿單、服藥紀錄各在不同地方；說明設計動機，不引用未量測的錯誤率或療效。
3. **照片先變成待核對資料**。放合成袋與核對表單，突出原文、留白及使用者確認。
4. **每項說明都能回到來源**。展示一則咳服錠引用，以及用途、用法、完整安全欄的區別。
5. **理解題讓閱讀有回饋**。並列錯答解說、原文依據、改答與保存進度，再進入現場示範。
6. **從閱讀回到日常**。展示服藥紀錄與提醒入口；簡述已完成的Android鎖屏收件、點擊返回及正常排程案例。
7. **目前成果與下一步**。用「已驗證／仍待驗證」兩欄收尾，保留來源擴充與真實使用條件。

## 可說的成果與限制

雲端已實測辨識、核對保存、官方引用、4題錯答改正與重新登入保存。Android已拍攝螢幕上的合成袋並確認兩個藥名；獨立通用通知與正常排程提醒均由使用者確認鎖屏收到、點擊返回，下一分鐘未觀察到重複通知。
