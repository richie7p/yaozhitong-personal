# 本機操作與驗收

更新：2026-09-11。先用本機帳號與檔案資料庫，不需要 Google Cloud 或信用卡。NVIDIA 真實辨識／問答仍需要網路與有效 API 額度。

## 開啟網站

在專案目錄執行 `npm run build`，再執行 `npm start`，開啟 http://127.0.0.1:8080 。程式需持續執行；資料存在 `.local/db.json` 與 `.local/blobs/`。重啟後資料保留，但登入憑證失效，重新選擇本機帳號即可。

- **本機使用者**：自己的藥品、健康資料、提醒、藥箱與問答。
- **本機家人**：獨立空白帳號，接受邀請後才看得到授權紀錄。
- **本機管理員**：帳號資格、停用、仿單草稿發布、用量與失敗任務。

三個帳號是開發用身份，沒有真實 Google／Email 密碼註冊。正式登入、驗證信、FCM 推播仍須日後接 Firebase。現階段可測站內提醒，關閉程式後不會有背景鬧鐘。

## 可操作的完整流程

1. 新增藥品 → 選擇照片，或搜尋藥名、手動建檔。
2. 核對候選、劑量、單位、頻次。空白欄位可存草稿；未確認不能建立提醒。
3. 我的藥品 → 仿單說明 → 展開原文，完成測驗；答錯可重答。
4. 用藥問答 → 選藥 → 提問。失敗時輸入保留；帳號與設定的 AI 處理紀錄可用原輸入重試。
5. 排定提醒 → 自行輸入時間 → 今日總覽打卡；服藥紀錄可更正。
6. 家庭藥箱 → 新增存量與效期 → 編輯或標記已處理。
7. 家人照護 → 產生邀請碼 → 另一個瀏覽器以本機家人接受 → 查看唯讀紀錄 → 取消授權。
8. 帳號與設定 → 修改健康資料、匯出資料；刪除帳號會清除該本機身份的資料，不能靠重新登入恢復。

## 自動驗收

```powershell
npm run check:local
```

執行後端／權限／資料隔離／檔案並行測試、桌面與手機尺寸瀏覽器流程、真實程式重啟及帳號刪除。每輪在獨立目錄測試，不改動本機使用者資料，不呼叫付費 NVIDIA。

模型實測另行明確執行，會消耗額度：

```powershell
npm run check:vision
npm run check:local:ai
```

影像測試為 7 張另外建立的合成開發圖片，沒有動用保留測試集。完整 AI 測試使用隔離本機服務、兩份已核對官方仿單與虛構患者，經真實 NVIDIA 執行照片、校正、說明、測驗、問答與交互作用。`check:local:ai` 使用目前 `dist/` 產物，修改程式後先建置。

結果保存在 `.local/reports/`。一般回歸 48＋10 項已通過；真實 NVIDIA 最新完整瀏覽器測試曾遇問答逾時，另驗證原請求重試完成但回覆資料不足，詳見 `docs/VALIDATION.md`。這些是軟體驗收，不能替代 50 張真實去識別化藥袋、100 題專家標註問答、實機 Android 與長時間運行測試。
