# 後續官方來源解析計畫

2026-10-23 夜間已將全部 6,703 份待處理 HTML 用目前規則重播，58 份結構候選均重新取得官方原檔並檢查，49 份新增發布、九份保留缺口。其餘來源需要新的完整結構證據；本輪維持已驗收的解析器。

## 下一批：保留原文清單的結構

目前有 **152 份沒有圖片、且右欄因未知元素被拒絕**的 HTML 候選。抽查的官方來源包含真實 `ul`／`li`／`ol` 清單；現行封閉章節語法尚未表達這些元素。這個數量是待解析的候選集合，通過清單規則後仍須核對其他表格、身分、全文與全部來源分支。

這 152 份原檔已逐一核對雜湊：124 份含無序清單、54 份含有序清單，兩者可重疊；其中 83 份含無序清單而沒有有序清單，可優先研究。其餘未知元素仍需各自分類。

優先研究無序清單：逐項保存原始標籤、父子關係、項目順序、屬性及文字，並為序列化前後的每個文字節點建立完整對應。任何隱藏、位置重排、不支援的子節點、未知條件或文字守恆差異繼續攔截。仿單的完整父欄與跨頁引用仍維持原邊界，不能只抽出較容易解析的項目。

有序清單另行處理。`start`、`reversed`、個別項目的 `value` 與瀏覽器產生的編號有閱讀語意；需要完整且可重推導的表示方式，再評估是否加入來源格式。第一階段先保留這些情況，不省略編號或自行猜測。

回歸資料須包含官方原始樣本與合成負例：巢狀清單、空項、清單前的共同條件、清單後的例外、隱藏內容、CSS 重排、未知媒體、錯誤父子關係及表格內清單。發布工具須獨立從原始位元組推導同一份結構證據，再執行全部已發布來源讀取與字面引用回播。

## PDF 與圖片來源

另有 6,473 份複雜 PDF 候選，常同時存在多欄、表格、圖片、缺少文字或不同引擎的文字順序差異。優先從完整頁面與字元幾何證據尋找可證明的同型結構；含圖或掃描頁須逐頁視覺核對。取得 OCR 草稿後，仍需獨立的字面與版面核對程序。

上述工作沿用完整許可證字號、現行產品身分、全部來源分支及頁面完整性的檢查。每批先準備固定候選與原始證據，再採只新增的發布與完整讀回。實際數量依通過證據的來源統計；帳號、配額與既有來源保持原設定。
